display

scale 200%
----------
This is an integer scale.
There is an option for fractional scale

```sh
gsettings set org.gnome.mutter experimental-features "['scale-monitor-framebuffer']"
```

But it incurs more load on GPU :(
So I stick with integer scale.

gdm
===
exclude root login, it was proposed after I did so at arch installation step,
in chroot...

See https://help.gnome.org/admin/gdm/stable/configuration.html.en#daemonconfig

Edit /etc/gdm/custom.conf:

```
[daemon]
# Uncomment the line below to force the login screen to use Xorg
# WaylandEnable=false
Exclude=root
```

> This does not solve the issue :((
